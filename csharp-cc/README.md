# Connected Components (C# / .NET 8)

Курсова робота: Алгоритм пошуку компонент зв'язності графа.
Послідовна (DFS) та паралельна (Lock-free Union-Find) реалізації.

## Швидкий старт для курсової

```bash
# 1. Запуск C# програми
dotnet run -c Release

# Натисніть 5 (згенерує 4 датасети: sparse/medium/dense + large)
# Натисніть 4 (запустить бенчмарк, видасть таблиці і збереже CSV)

# 2. Побудова графіків з результатів (потрібен Python + matplotlib)
pip install matplotlib
python plot_results.py
```

Після цього у директорії `testdata/` з'являться:
- `benchmark_results.csv` — сирі дані бенчмарку
- `plot_time.png` — графік часу виконання
- `plot_speedup.png` — графік прискорення
- `plot_density.png` — порівняння щільностей

Ці зображення вставляєте в курсову на місце рисунків.

## Опис тестових датасетів

| Назва | Вершини | Ребра | Степінь | Щільність | Призначення |
|---|---|---|---|---|---|
| sparse | 100 000 | 200 000 | ~4 | дуже мала | рідкі реальні графи |
| medium | 100 000 | 2 000 000 | ~40 | середня | проміжний випадок |
| dense | 100 000 | 10 000 000 | ~200 | велика | щільні структури |
| large | 1 000 000 | 5 000 000 | ~10 | мала | масштаб (10× розмір) |

Перші три датасети мають **однакову кількість вершин**, але різну
кількість ребер — це дозволяє ізолювати вплив щільності.
Четвертий датасет має значно більше вершин — для дослідження масштабованості.

## Алгоритми

### Sequential — DFS зі стеком
Класичний обхід у глибину з явним стеком. O(V + E).

### Parallel — Lock-free Union-Find
Атомарні CAS-операції через `Interlocked.CompareExchange`.
Оптимізації: union by rank, path splitting.
